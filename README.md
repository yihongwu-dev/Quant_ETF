# 广发 ATR-ETF 网格策略演讲稿：分步复现工具包

这是根据用户上传的19页演讲版PDF **第6—10、17—18页** 编写的本地教学复现代码。不是原券商程序；所有回看周期和交易执行口径必须在报告中注明。**原研报未完整披露N/N1、执行价、换手成本和完整历史样本筛选口径，无法承诺与原始收益一致。**

## 安装

```bash
python -m pip install -r requirements.txt
```

## 目录

把六只已下载指数CSV放进 `data/raw/index/`，允许文件名例如 `000300.csv`、`sh000300.csv`、`000688_tx_with_code.csv`（文件名须包含6位指数代码）。

把六只已下载ETF CSV放进 `data/raw/etf/`，例如 `510300_etf.csv`。**不要放重复代码的多个版本。**

ETF分红保存到 `data/raw/dividends/510300_dividend.csv` 等，保留包含 `日期`、`累计分红` 列的**完整历史表**，不是前五条。复制/下载之前，务必核实除息日、各次分红金额以及份额折算。

## 一步一步运行

1. `python atr_etf_reproduce.py check` 检查存在的CSV与起止日期
2. `python atr_etf_reproduce.py indicators --n 20 --n1 20` 计算TR、ATR、NATR、仓位及择时信号
3. `python atr_etf_reproduce.py index --n 20 --n1 20` 用指数模拟基础/4种择时网格，输出2019与2022起始净值图及指标
4. `python download_dividends_once.py` 下载6只ETF累计分红（可选，需要网络，已有文件自动跳过；若接口报错不自动重试）
5. `python atr_etf_reproduce.py portfolio --n 20 --n1 20` 计算固定六ETF的**择时策略2近似组合**，导出净值、仓位、收益与分年度表现

`--fee-bps 5` 可用于交易费率敏感性，5个基点是测试假设，不是研报原值。

## 教学版重要假设

- **按研报第6页公式** TR=max(H-L,abs(H-prevC),abs(L-prevC))；ATR为简单移动平均；NATR=(C-MA(C,N))/ATR；`N=20`和`N1=20` **是教学假设，研报演讲版未完整披露**。
- **按第7页表1** 中枢50%，NATR每跨一档，仓位加减10个百分点，截断0—100%；四种择时改进按照第9页表2实现。信号用截至t日收盘数据计算，**t+1日收盘才执行、t+2日收益才计入新仓位**，权重在每日收益上`shift(2)`（保守实现，与原研报未知执行假设可能不同）。
- 第一版单指数策略，用指数点位模拟配置，其回测是指数**模拟**，不是ETF实际可买卖净值。
- 六宽基组合为**固定六只ETF**，不执行20亿元规模和60日成交额筛选，也不动态换入同指数最大规模ETF，所以不是研报完整ETF组合；仅按当前有效六只固定ETF动态计算N和每只1/N上限。
- ETF剩余资金现金收益设为0，**未配置短融ETF**；分红事件按除息日即时再投资近似；未提供分红文件则**暂不计分红**，输出的`etf_total_returns_provisional.csv`不是真实完整总收益。
- 512100在2022年9月2日份额合并：每1份旧份额变成0.36555份新份额（2022年9月5日恢复交易）；代码在恢复交易日调整收益。其他ETF如存在历史折算需追加相应公司行动处理，尤其注意各ETF原始全历史可能有其他折算。程序在2019年后大于40%的收益时停止，防止显著错误。
- 请先核验分红文件完整性和ETF行情缺失交易日，再用于正式研究。

## 主要结果文件

- `outputs/features/000300_n20_n120.csv`：指数ATR、NATR、择时、基础和四种改进仓位
- `outputs/index_metrics.csv`：单指数基础/择时策略的2019和2022起点绩效
- `outputs/figures/`：指标、仓位、净值等PNG图表
- `outputs/portfolio_daily.csv`：固定六ETF组合净值与权益仓位
- `outputs/portfolio_metrics.csv`、`outputs/portfolio_annual_returns.csv`：组合绩效和分年度结果
